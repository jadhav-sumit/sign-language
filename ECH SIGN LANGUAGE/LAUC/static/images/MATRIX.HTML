Matrix

A matrix is a rectangular array of rows and columns which may contain numbers, symbols, or expressions.

Characteristics of a Matrix

  • A matrix is enclosed in extended square brackets.
  • The size or order of the matrix is the number of rows and columns, e.g., 2x4.
  • Each item in a matrix is called an entry or element.
  • A matrix is usually denoted by a capital letter, e.g., A or B.
  • Each entry is denoted by a lowercase letter with subscript indicating row and column, e.g., a2,3.
  • Matrices are categorized according to order: square, diagonal, etc.
  • Operations include addition, subtraction, and multiplication (for same-size matrices).

Types of Matrices

  • Row, Column, Square, Rectangular, Null
  • Specialized: Diagonal, Triangular, Identity, Scalar, Symmetric, Orthogonal

Square Matrix

A square matrix has the same number of rows as columns.

Identity Matrix

An identity matrix has 1s on the main diagonal and 0s elsewhere.

Null (Zero) Matrix

A zero matrix has all elements equal to 0.

Diagonal Matrix

A square matrix where all non-diagonal entries are zero.

Symmetric Matrix

A symmetric matrix is equal to its transpose.

Skew-Symmetric Matrix

A square matrix whose transpose equals its negative.
